# 🚀 راهنمای جامع و صفر تا صد راه‌اندازی دیتابیس MySQL، سرور بک‌اند و فرانت‌اند

این سند شامل تمام اطلاعات و دستورالعمل‌های لازم برای ساخت جداول دیتابیس **MySQL**، تنظیمات محیطی (`.env`)، اجرای سرور بک‌اند (Backend) و اجرای فرانت‌اند (Frontend) می‌باشد.

---

## 📌 چرا قبل‌تر SQLite نمایش داده می‌شد؟
پروژه به گونه‌ای طراحی شده است که در صورت عدم اتصال یا روشن نبودن سرویس MySQL روی سیستم شما، به صورت هوشمند از دیتابیس SQLite پشتیبانی محلی (Fallback) استفاده کند تا برنامه متوقف نشود. 

**برای استفاده مستقیم از MySQL:** فقط کافیست دیتابیس MySQL خود را روشن کنید و تنظیمات فایل `.env` را انجام دهید. سرور در هنگام استارت آپ به طور خودکار به **MySQL** متصل شده و پیغام زیر را در کنسول نمایش می‌دهد:
`🐬 MySQL Database initialized and connected successfully on database: messenger_db!`

---

## ⚙️ ۱. تنظیم متغیرهای محیطی (`.env`)

یک فایل با نام `.env` در ریشه پروژه ایجاد کرده (یا از روی `.env.example` کپی کنید) و اطلاعات لایو دیتابیس MySQL خود را وارد کنید:

```env
# تنظیمات پورت سرور
PORT=3000

# تنظیمات دیتابیس MySQL
MYSQL_HOST="localhost"
MYSQL_PORT=3306
MYSQL_USER="root"
MYSQL_PASSWORD="your_mysql_password"
MYSQL_DATABASE="messenger_db"

# آدرس دامنه یا سیستم
APP_URL="http://localhost:3000"
```

---

## 🗄️ ۲. نحوه ساخت دیتابیس و اجرای مایگریشن (MySQL Migration)

برای ساخت جداول و درج داده‌های اولیه دو روش استاندارد وجود دارد:

### روش اول: اجرای اسکریپت اتوماتیک Node.js (پیشنهادی)
در ترمینال پروژه دستور زیر را بزنید:

```bash
npm run migrate:mysql
```
*این دستور به صورت خودکار دیتابیس `messenger_db` را ایجاد کرده و تمامی جداول (`users`, `messages`, `rooms`, `contacts`, `system_settings` و...) را با ساختار utf8mb4 و داده‌های پیش‌فرض ایجاد می‌کند.*

---

### روش دوم: وارد کردن فایل SQL مستقیم در phpMyAdmin یا MySQL Workbench
فایل آماده اسکریپت SQL در مسیر زیر قرار دارد:
`server/db/schema_mysql.sql`

دستور اجرا در ترمینال یا CMD:
```bash
mysql -u root -p < server/db/schema_mysql.sql
```

---

## 💻 ۳. نحوه اجرای سرور بک‌اند و فرانت‌اند

این پروژه از سیستم یکپارچه **Express + Vite + WebSockets** استفاده می‌کند. نیازی به اجرای مجزای فرانت و بک نیست و هر دو روی پورت **3000** اجرا می‌شوند.

### الف) اجرای حالت توسعه (Development)
برای اجرای سرور و فرانت به‌صورت زنده (Hot Reload):

```bash
npm run dev
```
🌐 **آدرس دسترسی در مرورگر:** `http://localhost:3000`

---

### ب) اجرای حالت پروداکشن (Production)
برای بیلد نهایی و اجرای عملیاتی:

```bash
# ۱. کامپایل فرانت‌اند و بیلد سرور
npm run build

# ۲. اجرای سرور کامپایل شده
npm run start
```

---

## 🐳 ۴. اجرای کامل با Docker Compose (پیشنهادی برای محیط یکپارچه)

اگر می‌خواهید دیتابیس MySQL و سرور برنامه بدون نیاز به نصب دستی MySQL روی سیستم‌عامل اجرا شوند:

```bash
# اجرای کانتینر MySQL 8.0 و سرور برنامه
docker-compose up -d
```

## 📋 لیست جداول ساختار یافته MySQL

| نام جدول | توضیحات کاربردی |
| :--- | :--- |
| `users` | اطلاعات کاربران، شماره تماس، نام کاربری و نقش‌ها |
| `rooms` | کانال‌های خبری، گروه‌ها و چت‌های خصوصی |
| `room_members` | اعضای کانال‌ها و گروه‌ها همراه با سطح دسترسی |
| `messages` | پیام‌های متنی، صوتی، تصویر، ویدئو و فایل‌ها |
| `attachments` | مشخصات و مسیر ذخیره فایل‌های پیوست |
| `message_seens` | تیک دوم و وضعیت رسیدن/خوانده شدن پیام‌ها |
| `message_reactions` | ایموجی‌ها و واکنش‌های ثبت‌شده روی پیام‌ها |
| `system_settings` | تنظیمات فنی سیستم، حجم آپلود و مجوزها |
